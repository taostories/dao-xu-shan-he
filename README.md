# 稻续山河

写实田间研学互动故事：跟随李爷爷走进稻田，通过三项小游戏了解粮食与农耕，思考禾下乘凉梦与青年接续。

在线体验：https://taostories.github.io/dao-xu-shan-he/

## 运行

静态 HTML、CSS、JavaScript，无需安装或构建。打开 index.html，或使用任意静态服务器。GitHub Pages 从 main 分支根目录发布。

## 交互

- 打谷入仓：节奏脱粒、拖动扬谷、称重。
- 守住三块田：进入即开始，每田独立按钮调水，长按修补。
- 稻株寻穗：观察花药，三次选择机会。
- 两道对话选择、共同结尾、章节重玩和本地存档。

## 素材与制作

剧情与交互由创作者提出并迭代，Codex 辅助代码实现、文本调整与测试；图片由创作者使用 AI 绘图工具生成并提供，部分素材经过透明背景处理。此仓库公开展示不代表授予图片或作品再利用许可。

当前五张场景、独立封面、尾声全景、第一关五种道具及第三关两种稻穗均已接入；李爷爷独立立绘待补充，缺图时隐藏，不影响流程。

人物和村庄经历为虚构叙事，小游戏数值为教学规则，不是农业预测。梦的两层含义为本作主题阐释。
